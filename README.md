# MindSpace - платформа психологической поддержки

Учебный проект по дисциплине «Технология разработки программных продуктов и обеспечения».

## О проекте

MindSpace - это веб-приложение для онлайн-записи к психологам. Пользователь может выбрать специалиста, посмотреть его профиль, выбрать удобное время и оставить заявку. Также на сайте есть психологические тесты и дневник настроения.

## Технологии

- HTML5
- CSS3 (адаптивная вёрстка, CSS-переменные, тёмная тема)
- JavaScript (Vanilla JS, localStorage, Canvas API для графика)
- Figma (дизайн-макет)
- Git / GitHub Pages

## Основной функционал

- Каталог психологов - 6 специалистов с фильтрами по специализации, цене и поиску
- Профиль специалиста - вкладки «О себе», «Образование», «Расписание»
- Запись на сессию - пошаговая форма (3 шага) с валидацией
- Избранное - сохранение психологов в localStorage
- Дневник настроения - календарь и график на Canvas
- Психологические тесты - 3 теста (стресс, тревожность, выгорание)
- Админ-панель - управление психологами и слотами (логин: admin / admin123)
- Тёмная тема - переключение с сохранением выбора
- Cookie-баннер, прелоадер, прогресс-бар, кнопка «наверх»
