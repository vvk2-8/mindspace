## Что это за сайт

MindSpace - сайт, где можно записаться к психологу онлайн. Я выбрала эту тему, потому что сейчас многие ищут специалиста через интернет, а удобных площадок для записи не так много. На сайте есть каталог психологов, можно посмотреть профиль, выбрать время и оставить заявку. Ещё я добавила дневник настроения и небольшие тесты - чтобы человек мог немного разобраться в своём состоянии, прежде чем идти к специалисту.

## Что умеет сайт

- Каталог из 6 психологов, есть фильтр по специализации, цене и поиск по имени
- Карточка психолога с вкладками: о себе, образование, расписание
- Запись на сессию в 3 шага, с проверкой данных
- Избранное - можно сохранить психолога, чтобы не искать заново
- Дневник настроения - календарь на месяц и график
- Три теста: на стресс, тревожность и выгорание
- Админка, куда можно войти под admin / admin123. Там можно добавлять, редактировать и удалять психологов, а также управлять свободными окошками
- Тёмная тема
- Мелочи вроде прелоадера, cookie-баннера, кнопки "наверх" и прогресс-бара при прокрутке
