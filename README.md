# MindSpace

Учебный проект по дисциплине "Технология разработки программных продуктов и обеспечения".
Автор: Фионина Виктория Романовна, группа ИС24-2, 3 курс, ВВФ МТУСИ.
Преподаватель: Салопаев Владислав Игоревич (@bye1337).

## Идея

MindSpace - сайт, где можно записаться к психологу онлайн. Тему выбрала потому что сама сталкивалась с тем, что найти специалиста сложно: либо непонятные сайты, либо надо куда-то звонить. Захотелось сделать что-то удобное, где всё видно сразу: кто принимает, сколько стоит, когда есть свободное время.

Помимо записи добавила ещё пару полезных штук: дневник настроения и небольшие тесты. Мне показалось, что это поможет человеку чуть лучше понять своё состояние, прежде чем идти к специалисту.

## Что использовала

- HTML, CSS, JavaScript
- Figma для макета
- GitHub Pages чтобы сайт был по ссылке

## Что умеет сайт

- Каталог из 6 психологов. Есть фильтр по специализации, по цене и поиск по имени
- Карточка каждого психолога: о себе, образование, свободные окошки
- Запись на сессию в 3 шага: выбрать психолога, выбрать время, ввести контакты
- Избранное: можно сохранить специалиста и потом не искать заново
- Дневник настроения: календарь на месяц и график
- Три теста: на стресс, тревожность и выгорание
- Админка для управления психологами и слотами (вход admin / admin123)
- Тёмная тема
- Плюс мелочи: прелоадер, cookie-баннер, кнопка "наверх", прогресс-бар
